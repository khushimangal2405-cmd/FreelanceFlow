# FreelanceFlow

FreelanceFlow is a full-stack freelance management platform for managing clients, projects, tasks, time tracking, invoices, and business analytics.

## Features

- Client Management
- Project Management
- Task Management
- Time Tracking
- Invoice Management
- Dashboard & Analytics
- Revenue Tracking
- JWT Authentication

## Tech Stack

- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- JavaScript
- CSS

## Project Structure

- `client/` — React frontend
- `server/` — Node.js + Express backend
